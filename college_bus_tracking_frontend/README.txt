# College Bus Tracking System – Frontend

## Files
- `index.html` – complete responsive frontend (HTML, CSS and JavaScript).

## Run
1. Extract the ZIP file.
2. Open the `index.html` file in Chrome, Edge, or Firefox.
3. Choose Student, Driver, or Admin.
4. Enter any demo user ID and password, then click Login.

## Included screens
- Login with Student / Driver / Admin role selection
- Dashboard with bus status cards
- Live tracking map using Leaflet and OpenStreetMap
- Bus routes
- Route details and estimated arrival (demo values)
- Notifications
- Profile
- Driver Start Trip / Stop Trip controls

## Important
This is a frontend demonstration only. Login accepts any non-empty ID and password. Bus locations, route details, ETAs and notifications are sample data, not live GPS data. A real system needs a backend, database, secure authentication, and a GPS-enabled driver phone/device that sends location updates.
The map requires an internet connection to load Leaflet and OpenStreetMap tiles.
